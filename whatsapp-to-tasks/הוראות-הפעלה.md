# 📋 WhatsApp → Excel Tasks – הוראות הפעלה

---

## איך זה עובד?

1. מפעילים את התוכנה על **המחשב**
2. סורקים קוד QR עם **הנייד** (פעם אחת בלבד)
3. שולחים הודעה **לעצמנו** בוואטסאפ
4. המשימה נכנסת אוטומטית לקובץ אקסל על המחשב

---

## לפני שמתחילים – מה צריך?

| דרישה | איך מורידים |
|-------|-------------|
| Node.js (גרסה 18 ומעלה) | [nodejs.org](https://nodejs.org) ← לחצי על "LTS" |
| מפתח API של Anthropic | [console.anthropic.com](https://console.anthropic.com) ← API Keys ← Create Key |

---

## שלב 1 – התקנה (פעם אחת בלבד)

פתחי **Command Prompt** (cmd) על המחשב:

```
cd whatsapp-to-tasks
npm install
```

> ההתקנה לוקחת כמה דקות – היא מורידה את Chromium. זה תקין.

---

## שלב 2 – הגדרת מפתח API

1. בתיקיית `whatsapp-to-tasks` מצאי את הקובץ `.env.example`
2. העתיקי אותו ושמרי אותו בשם `.env` (ללא המילה "example")
3. פתחי את `.env` בנוטפד והחליפי את הטקסט:

```
ANTHROPIC_API_KEY=sk-ant-...
```

בכך שתדביקי את המפתח האמיתי שלך במקום `sk-ant-...`

---

## שלב 3 – הפעלה

בחלון ה-cmd:

```
npm start
```

## שלב 4 – סריקת QR מהנייד

> **חשוב:** הקוד מופיע על **מסך המחשב** – סורקים אותו עם הנייד.

1. פתחי **וואטסאפ** בנייד
2. לחצי על **שלוש הנקודות** ⋮ (למעלה מימין)
3. בחרי **מכשירים מקושרים**
4. לחצי **קשר מכשיר**
5. כוונני את מצלמת הנייד לקוד QR שעל מסך המחשב

אחרי סריקה מוצלחת יופיע בחלון cmd:

```
✅ מחובר לוואטסאפ!
🎯 מאזין להודעות ל"הודעות שמורות"...
```

---

## שלב 5 – שליחת משימה

1. פתחי וואטסאפ בנייד
2. גלגלי למעלה ברשימת השיחות עד שתמצאי **"הודעות שמורות"**  
   *(זה הצ'אט עם תמונת הפרופיל שלך)*
3. שלחי כל הודעה, לדוגמה:

```
לקנות חלב ולחם
```
```
להגיש דוח עד יום שלישי – דחוף!
```
```
לקבוע תור לרופא בשבוע הבא
```

תוך שניות יופיע בחלון cmd:

```
📩 הודעה חדשה: "להגיש דוח עד יום שלישי – דחוף!"
🤖 Claude מנתח...
✅ שורה 1 נוספה: [גבוהה] "הגשת דוח"
   📅 תאריך יעד: יום שלישי
   🏷  קטגוריה: עבודה
```

והמשימה תיכנס לקובץ `tasks.xlsx` שנמצא באותה תיקיה.

## שאלות נפוצות

**האם צריך לסרוק QR בכל פעם?**
לא. הסריקה נשמרת בתיקיית `.wwebjs_auth`. בפעמים הבאות רק מריצים `npm start` וזהו.

**איפה נשמר קובץ האקסל?**
בתיקיית `whatsapp-to-tasks` בשם `tasks.xlsx`. אפשר לשנות את המיקום בקובץ `.env`:
```
EXCEL_PATH=C:\Users\שמך\Desktop\משימות.xlsx
```

**האם התוכנה חייבת לרוץ כל הזמן?**
כן – כל עוד חלון ה-cmd פתוח ו-`npm start` רץ, ההודעות נקלטות. אפשר למזער את החלון.
