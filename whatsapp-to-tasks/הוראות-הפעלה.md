# 📋 WhatsApp → Excel Tasks

שלחי הודעה לעצמך בוואטסאפ → Claude מנתח → נכנס אוטומטית לאקסל.

---

## דרישות מקדימות

- **Node.js 18+** – [nodejs.org](https://nodejs.org)
- **מפתח API של Anthropic** – [console.anthropic.com](https://console.anthropic.com)

---

## התקנה (פעם ראשונה בלבד)

```bash
cd whatsapp-to-tasks
npm install
```

> **הערה:** ההתקנה מורידה את Chromium (כ-120MB) עבור whatsapp-web.js. זה נורמלי.

---

## הגדרת מפתח API

```bash
copy .env.example .env
```

פתחי את `.env` ומלאי את המפתח:
```
ANTHROPIC_API_KEY=sk-ant-...
```

---

## הפעלה

```bash
npm start
```

בפעם הראשונה יופיע קוד QR בטרמינל:

```
📱 סרוק את קוד ה-QR עם הוואטסאפ שלך
[██████████████]
[██    ████    ]
...
```

**איך לסרוק:**
1. פתחי וואטסאפ בנייד
2. לחצי על שלוש הנקודות → **מכשירים מקושרים** → **קשר מכשיר**
3. סרקי את הקוד

לאחר הסריקה המערכת מזכירה:
```
✅ מחובר לוואטסאפ!
🎯 מאזין להודעות ל"הודעות שמורות"...
```

---

## שימוש

שלחי הודעה **לעצמך** בוואטסאפ (צ'אט "הודעות שמורות"):

| הודעה | מה Claude מחלץ |
|-------|----------------|
| `לקנות חלב ולחם` | משימה: לקנות חלב ולחם, קטגוריה: קניות, עדיפות: נמוכה |
| `ישיבה עם הלקוח ביום שלישי בשעה 14:00` | משימה: ישיבה עם לקוח, תאריך יעד: XX/XX/XXXX, קטגוריה: עבודה |
| `להגיש דוח רבעוני עד סוף החודש – דחוף!` | משימה: הגשת דוח רבעוני, עדיפות: גבוהה |

---

## מבנה קובץ האקסל

| # | תאריך קבלה | משימה | עדיפות | תאריך יעד | קטגוריה | סטטוס | הודעה מקורית | הערות |
|---|------------|-------|--------|-----------|---------|-------|---------------|-------|

- **עדיפות גבוהה** – אדום 🔴  
- **עדיפות בינונית** – כתום 🟠  
- **עדיפות נמוכה** – ירוק 🟢  
- **סטטוס** מתחיל תמיד כ-"פתוח" – שני ידנית לפי הצורך

---

## נתיב מותאם לאקסל

אם תרצי שהקובץ יישמר במקום אחר, הוסיפי לקובץ `.env`:
```
EXCEL_PATH=C:\Users\שמך\Desktop\משימות.xlsx
```

---

## פתרון בעיות

**הטרמינל נסגר אחרי QR?**  
ודאי ש-Node.js גרסה 18 ומעלה: `node --version`

**"Missing ANTHROPIC_API_KEY"?**  
ודאי שיצרת קובץ `.env` (לא `.env.example`) עם המפתח.

**החיבור נשמר?**  
כן – תיקיית `.wwebjs_auth` שומרת את ה-session. בפעם הבאה לא תצטרכי לסרוק שוב.
