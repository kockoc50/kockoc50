# ניהול משמרות – נהגי משאיות

אפליקציית ווב עצמאית (HTML/CSS/JS, ללא תלות בשרת) לניהול שיבוץ נהגי משאיות בשלוש משמרות יומיות:

- **משמרת בוקר** — 06:00–14:00
- **משמרת צהריים** — 14:00–22:00
- **משמרת לילה** — 22:00–06:00

## תכונות

- **ניהול נהגים** — הוספה, עריכה, השבתה של נהגים (שם, טלפון, רישיון, משאית קבועה).
- **לוח משמרות שבועי** — טבלת ימים × משמרות, לחיצה על תא לשיבוץ נהג. תומך בכמה נהגים/משאיות באותה משמרת.
- **בדיקת התנגשויות ומנוחה** — התרעה כאשר נהג משובץ פעמיים באותו יום, או כשאין מנוחה מספקת בין משמרת לילה למשמרת בוקר עוקבת.
- **סיכום שעות שבועי** לכל נהג.
- **העתקת שבוע** ללוח השבוע הבא בלחיצה אחת.
- **ייצוא ל-CSV** והדפסה של הלוח.
- כל הנתונים נשמרים מקומית בדפדפן (`localStorage`) — אין צורך בשרת או חיבור לאינטרנט.

## הפעלה

פתחו את `shift-management/index.html` ישירות בדפדפן, או הגישו את התיקייה עם שרת סטטי כלשהו, למשל:

```bash
npx http-server shift-management -p 8080
```

ואז גשו ל-`http://localhost:8080`.

## מבנה

```
shift-management/
  index.html   # מבנה הדף והמודאלים
  style.css    # עיצוב (RTL, עברית)
  app.js       # לוגיקה: נהגים, לוח משמרות, שמירה ב-localStorage
```
